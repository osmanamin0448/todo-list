# Webpack Template Repository
This repository serve as a template for webpack projects which prevent the process having to set up webpack repository,configuring and install dependencies manually.

## Webpack Configuration files
- webpack.common.js
- webpack.dev.js
- webpack.prod.js

## Dependencies
- css-loader
- html-loader
- html-webpack-plugin
- style-loader
- webpack
- webpack-cli
- webpack-dev-server
- webpack-merge

## How To Get This Webpack Template Repository
```bash
  git clone git@github.com:osmanamin0448/webpack-template.git
```
## How to Install Dependencies
**NOTE** this should be called once and all dependencies listed in **package.json file** will be installed
 ``` bash
 npm install
 ```

## How to Start Development Server
```bash
npm run start
```

## How To Stop Development Server
Press **control** + **c** from the keyboard
 
## How To Build Project into Production
```bash
npm run build
```
